# Docker

La contenerización de cada microservicio (un `Dockerfile` por servicio + `docker-compose.yml`
para levantar todo junto) se implementará en el **Entregable 3**, según la proyección del
documento de la asignatura:

> "En el Entregable 3 se profundizarán la distribución, integración avanzada, despliegue y
> videomemoria."

Por ahora, todos los microservicios corren localmente con Node.js (ver `README.md` en la
raíz de `backend/` para instrucciones de ejecución).
